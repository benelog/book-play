# 원문 텍스트 — Peter and Wendy

J. M. Barrie의 원문(1911)은 전 세계 퍼블릭 도메인입니다(작가 1937년 사망). 이 폴더의 `pg26654.txt`는
Project Gutenberg eBook #26654(https://www.gutenberg.org/ebooks/26654)의 Plain Text UTF-8 파일 그대로입니다.

- `./start.sh` 또는 `python3 tools/embed-text.py`가 `text/book.js`로 변환하면 17개 장으로 자동 분할됩니다.
- Gutenberg 머리말·꼬리말·목차는 파서가 걸러 냅니다. 파일 이름의 `pg26654` 때문에 출처 표기가 자동으로 붙습니다.
- 장 제목은 `CHAPTER I` 형식이고 다음 줄에 제목이 옵니다. 분할이 어긋나면 장 사이에 `===` 줄을 넣어 주세요.

영국에서는 Great Ormond Street 병원이 피터 팬에 대한 영구 사용료 권리를 가지지만(1988년 저작권법), 영국 안에서만 적용됩니다.
