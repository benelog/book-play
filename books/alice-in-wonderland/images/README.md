# 삽화 넣기 — John Tenniel

John Tenniel(1914년 사망)의 원본 삽화는 전 세계 퍼블릭 도메인입니다.

1. https://www.gutenberg.org/ebooks/11 에서 HTML zip을 내려받으면 `images/` 폴더에 그림 파일이 들어 있습니다. 삽화만 모은 https://www.gutenberg.org/ebooks/114 를 써도 됩니다.
2. 장마다 대표 그림을 하나 골라 `chapter-01.jpg` … `chapter-12.jpg` 이름으로 이 폴더에 넣습니다. png도 됩니다.
3. 파일이 없는 장은 제목만 있는 기본 그림을 보여 줍니다. 이 책에는 `art.js`가 없습니다.

권장 비율은 4:3 입니다. 다른 비율은 가운데를 기준으로 잘라서 채웁니다.
