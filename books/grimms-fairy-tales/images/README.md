# 삽화 넣기 — Arthur Rackham

Arthur Rackham(1867–1939)이 1909년판 *The Fairy Tales of the Brothers Grimm*에 그린 삽화는
화가가 1939년에 세상을 떠났고 그림도 1909년에 발표되었으므로 퍼블릭 도메인입니다.

1. Wikimedia Commons의 [Category:Arthur Rackham](https://commons.wikimedia.org/wiki/Category:Arthur_Rackham)
   (특히 그림 형제 동화 관련 하위 분류)에서 원하는 그림을 내려받습니다.
   Project Gutenberg #2591에는 삽화가 들어 있지 않으므로, 그림은 따로 구해야 합니다.
2. 이야기마다 대표 그림을 하나 골라, `scenes.js`의 장 번호에 맞춰 이 폴더에 넣습니다.

- 권장 비율은 **4:3** 입니다. 다른 비율은 가운데를 기준으로 잘라서 채웁니다.
- 확장자는 jpg 외에 jpeg, png, webp, gif, svg 순으로 찾습니다.
- 파일이 없는 장은 **제목만 있는 기본 그림**을 보여 줍니다. 이 책에는 `art.js`가 없습니다.
- Rackham이 12편을 모두 그린 것은 아닙니다. 빠진 이야기는 Walter Crane, George Cruikshank,
  Hermann Vogel 등 다른 퍼블릭 도메인 화가의 삽화로 채워도 됩니다.
