# 삽화 넣기

`images/chapter-01.jpg` … `images/chapter-27.jpg` 이름으로 파일을 넣으면 해당 장의 삽화로 자동 표시됩니다.
확장자는 jpg, jpeg, png, webp, gif, svg 순서로 찾습니다. 파일이 없으면 이 폴더 옆의 `art.js`가 그린 대체 삽화(SVG)를 보여 줍니다. `tools/gallery.html?book=little-prince`에서 미리 볼 수 있습니다.

생텍쥐페리의 원본 수채화는 한국에서는 퍼블릭 도메인이지만 미국에서는 2039년까지 보호되므로,
Wikimedia Commons 같은 미국 서버에는 올라와 있지 않습니다. 소장한 책을 스캔하거나 국내에서 배포되는 판본의 이미지를 사용하세요.

권장 비율은 4:3 (예: 1200×900)입니다. 다른 비율은 가운데를 기준으로 잘라서 채웁니다.
