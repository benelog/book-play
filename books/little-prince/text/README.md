# 원문 텍스트 넣기

이 게임은 영어판 전체 텍스트를 **직접 불러와서** 사용합니다. 저장소에는 원문이 포함되어 있지 않습니다.

## 저작권 상황 (2026년 9월 기준)

| 대상 | 한국 | 미국 | 프랑스 |
|---|---|---|---|
| 프랑스어 원문 (생텍쥐페리, 1944년 사망) | 만료 (퍼블릭 도메인) | 2039년 1월 1일까지 보호 | 2032년까지 보호 |
| 생텍쥐페리의 원본 삽화 | 만료 (퍼블릭 도메인) | 2039년까지 보호 | 2032년까지 보호 |
| Katherine Woods 영역본 (1943, 역자 1968년 사망) | **2038년까지 보호** | 2039년까지 보호 | 보호 |
| Richard Howard 영역본 (2000) | 보호 | 보호 | 보호 |
| Jeff McNeill 영역본 (2019, CC BY-NC-ND 4.0) | 비상업·무수정·출처 표시 조건으로 이용 가능 | 동일 | 동일 |

"어린 왕자는 저작권이 만료됐다"는 말은 **프랑스어 원문과 삽화**에 대해서는 (한국 등 사후 70년 국가에서) 맞지만,
**영어 번역본은 별도의 저작물**이라 대부분 아직 보호 중입니다. 학습용 개인 사용을 위해 다음 중 하나를 권합니다.

1. **Jeff McNeill 번역본** — Creative Commons BY-NC-ND 4.0. 개인 학습 목적의 비상업적 이용은 허용됩니다.
   텍스트를 수정하지 말고, 게시·배포할 때는 역자 표기를 남기세요. 이 게임은 원문을 장 단위로 나눠 표시할 뿐 문장을 바꾸지 않습니다.
2. **직접 구매한 전자책**을 개인 용도로 텍스트 추출해 사용 (배포 금지).
3. 캐나다 등 사후 50년 국가에서만 퍼블릭 도메인인 Woods 번역본은 한국에서는 아직 보호 중이므로 권하지 않습니다.

## 자동 불러오기

이 폴더에 .txt 파일을 두고 `./start.sh`를 실행하면 `tools/embed-text.py`가 `text/book.js`를 만들고, 게임이 시작될 때 자동으로 27개 장으로 나눠 저장합니다. 파일 이름에 `mcneill`이 들어 있으면 역자 표기(CC BY-NC-ND 4.0)를 자동으로 붙입니다.

## 파일 형식

- 순수 텍스트(.txt, UTF-8)면 됩니다. 게임의 "원문 텍스트 불러오기" 화면에서 붙여 넣거나 파일을 선택하세요.
- 장 제목 줄이 `Chapter 1`, `CHAPTER I`, `I`, `1`, `1.`, `Chapter One` 중 어느 형식이어도 자동으로 나눕니다.
- 자동 분할이 27개 장으로 떨어지지 않으면, 각 장 앞에 `===` 한 줄을 넣어 주세요 (`===` 이전 텍스트는 버립니다).
- 문단은 빈 줄로 구분됩니다. 빈 줄이 하나도 없는 파일은 줄 단위로 문단을 나눕니다.

텍스트는 브라우저의 localStorage에만 저장되며 어디로도 전송되지 않습니다.
